Proyecto Flask - Unidad 3

Este proyecto corresponde al encargo de la Unidad 3 del ramo Programación Web.
Incluye:
- Menú principal con dos botones.
- Formulario de Ejercicio 1: cálculo de promedio y asistencia (escala 1–7, mínimo 4.0 para aprobar).
- Formulario de Ejercicio 2: cálculo del nombre más largo.
- Carpeta templates con los archivos HTML.
- Carpeta static/css con estilos.
- Archivo main.py con la lógica en Flask.
